Get it

From GitHub, in four steps.

It is not on npm. You build it from the repository.

Node 22.14 or newerOS Windows or LinuxGit and npm
  1. Clone the repository

    Source is open under the MIT licence.

    git clone https://github.com/IboTheSecond/hartii-operator-tools.git
cd hartii-operator-tools
  2. Install dependencies

    Scripts are not run during install.

    npm ci --ignore-scripts
  3. Run a tool

    Prints the commands and options. Use release, watch or replay in place of tx for the others.

    node packages/tx/bin/cli.mjs --help
  4. Optional: build the packages

    Builds five tarballs twice, compares their bytes, and writes SHA256SUMS to artifacts/packages. Install the core and the tools you want from those tarballs together.

    npm test
npm run pack:verify

Safety and limits

What it checks, and what it does not.

The tools check and refuse. They cannot promise an outcome on a live network.

Report a security issue
  • Your keys stay yoursIt never holds a key and has no signing-key option. You sign with your own signer, outside these tools.
  • Chains and zoneMainnet (chain 9) and chain 15000, on Cyprus-1 only. Other zones, Qi and zero destinations are refused.
  • The node is trustedThe RPC endpoint you choose is a trust dependency. Chain ID and identity checks do not prove a node is honest.
  • A failed broadcast is unknownThe same signed bytes may already be in the network. It is never retried automatically. Reconcile with a receipt before sending again.
  • Beta and unauditedNo outside audit. The upstream quais SDK is pinned to a pre-release, 1.0.0-alpha.54.
  • Mocks are not proofTests use local fixtures. A passing test is not evidence about a live network.
  • Local state mattersReservations live in a private folder on your machine. Losing it loses that knowledge. One process should own it.
